# The heap-34 misère quotient of Dawson's Kayles is countably infinite

For the octal game $0.07$, let $H_h$ be a heap of size $h$. A move removes two stones and replaces $H_h$, $h\ge2$, by $H_i+H_{h-2-i}$ for $0\le i\le h-2$, where a heap of size zero is omitted. A terminal position is N in misère play. For $k\ge0,m\ge2$,
$$
o^-(H_{25}+kH_{30}+mH_{34})=P
\quad\Longleftrightarrow\quad k\ge m\text{ and }k\equiv m\bmod2.
$$
In the universe of finite sums of heaps of size at most 34, $2nH_{30}$ and $2rH_{30}$ for $r>n$ are distinguished by adding $H_{25}+(2n+2)H_{34}$. This gives infinitely many classes, and the universe is countable. [Nowakowski, Problem A15](https://library.slmath.org/books/Book71/files/GONC6-04.pdf)

## Finite model and a cover of all counter values

Omit $H_{33}$ in the recursion, since the remaining universe is closed under moves and contains all displayed positions and distinguishing tests. Write a position as $Y+kD+mE$, $D=H_{30}, E=H_{34}$, with $Y$ containing background heaps of sizes 2 through 32 other than 30. Heaps of size 1 are inert. The [background data](certificate/background.json) acts on 664 labels by commuting maps $A_h$, generated from label 0. All labels are reachable. Consequently every product of generators has an action determined by its value on 0, giving a well-defined monoid of labels. Write $\beta(Y)$ for the label of $Y$.

The [outcome table](certificate/outcomes.json) takes a background label, reduced $m$ and reduced $k$. Write $\tau(t)=t$ for $t\le5$ and $6+(t\bmod2)$ otherwise. For $m\le5$ take $\rho(k,m)=(\tau(k),m)$. For $m\ge6$ put $s=4+(m\bmod2)$, $x=k-m+s$. Set $t=x$ if $x\ge1$, $t=0$ if $x\le0,k=0$, and $t=1+((k-1)\bmod2)$ otherwise. Take $\rho(k,m)=(\tau(t),s)$. The five inputs needed for the recursion are $(k,m),(k-1,m),(k+1,m),(k,m-1),(k+1,m-1)$. Use a sentinel for negative coordinates. Call the tuple of their reduced values the signature.

Every signature occurs in $0\le k,m\le13$. For $m\le7$ keep $k\le10$ and otherwise replace $k$ by $10+(k\bmod2)$, preserving the periodic columns of all five inputs. For $m\ge8,k\le1$, keep $k$ and replace $m$ by $8+(m\bmod2)$. Every valid input has internal $x\le0$ and the zero and parity tests agree. For $m\ge8,k\ge2$, put $d=k-m$. Every internal $x$ is $d$ plus an integer in $[3,7]$. For $d\le-7$, use $m'=10+(m\bmod2)$, $d'=-8+(d\bmod2)$. All five $x$ values stay nonpositive. For $d\ge3$, use $m'=8+(m\bmod2)$, $d'=4-(d\bmod2)$. All five $x$ values stay at least six, where $\tau$ depends only on parity. Otherwise use $m'=8+(m\bmod2),d'=d$. Take $k'=m'+d'$. The substitutions preserve all needed tests and give a total of 69 distinct signatures.

## Checking the misère recursion

Write $S(Y)$ for the set of possible pairs $(\delta,b')$ from a move on $Y$ yielding background label $b'$ and $\delta\in\{0,1\}$ new $D$ heaps. With $v_h=\beta(H_h)$, adding a background heap gives
$$
S(Y+H_h)=\{(\delta,b'v_h):(\delta,b')\in S(Y)\}
\cup\{(\delta,\beta(Y)v):(\delta,v)\in S(H_h)\}.
$$
For fixed label this operation preserves inclusion. The verifier regenerates 2,577 minimal option sets, each with a concrete background representative. Single heaps contain a saved set of their label, and applying any generator to a saved set contains another saved set in the resulting label. Thus each nonempty background contains a saved set of its label by induction. The empty background is handled separately, even when a nonempty background has label 0.

For each of the 69 signatures, all $D,E$ moves and all background moves from a candidate P position lead to candidate N positions. Background moves are generated by considering each moved heap and every label of the other background heaps. For any candidate N with no P option playing $D$ or $E$, every saved minimal set at its label contains a P option. The verifier also checks the empty-background cases and the misère terminal outcome. The cover extends these checks to all counter values and the inclusion argument to arbitrary background multiplicity. Since each move strictly reduces total stones, the table is correct by the outcome recursion.

For $\beta(H_{25})=31$, rows $m=2,\ldots,5$ give $k\ge m$ and matching parity. For $m\ge6$, $x\le0$ gives N in both rows 4 and 5. When $x>0$, the criterion on row $s$ is $x\ge s$ and $x\equiv s\bmod2$, equivalent to the claimed threshold.

## Reproduction

Run `python3 verify.py` from `certificate/` with Python assertions enabled. It regenerates the option sets and checks the recursion and threshold rows. The alternative `python3 verify_independent.py` performs an independent background computation and an SMT coverage check. The latter uses `z3-solver==5.4.1.0` in the tested environment.
